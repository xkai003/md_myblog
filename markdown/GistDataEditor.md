# 通用Gist JSON编辑器

> 纯前端单HTML文件工具，基于 GitHub Gist 实现云端JSON读写。自动识别数组字段动态生成表单，支持多行文本，无需部署后端服务。

## ✨ 功能特性
- ✅ 读取公开/私有Gist，公开Gist读取无需Token
- ✅ 根据JSON数组路径，自动解析字段动态渲染多行文本框
- ✅ 适配任意字段数量的JSON数组，不用修改代码
- ✅ textarea原生回车换行，解决双重转义`\\n`问题
- ✅ 一键新增数组条目并保存回远程Gist
- ✅ JSON格式化预览，Toast成功/失败弹窗提示
- ✅ 仅单个HTML文件，浏览器本地直接打开运行
- ✅ 数据全部存放在你自己的GitHub Gist，无第三方中转

## 📋 前置准备
1. 拥有GitHub账号
2. 创建Gist，内部建立你的`.json`数据文件
3. GitHub Fine‑grained Token（**保存写入必须，公开读取不需要**）
   - Token权限开启 `gist` 读写权限
   - Token仅页面内存临时使用，不会持久保存，切勿外泄

## 🚀 使用教程

### 页面参数说明
| 参数 | 说明 |
|------|------|
| Gist ID | Gist地址里那一串长ID字符串 |
| JSON文件名 | Gist内json完整文件名，**区分大小写** |
| GitHub Token | 读取公开Gist可留空；保存修改必填 |
| 目标数组路径 | 需要追加数据的数组路径 |

### 操作步骤
1. 将HTML文件保存本地，双击用浏览器打开
2. 填入 `Gist ID`、`JSON文件名`，公开读取可不填Token
3. 点击【读取Gist】拉取远程JSON数据，预览框显示内容
4. 填写**目标数组路径**，点击【自动生成表单(按路径解析字段)】
   > 依靠数组第一条样例数据自动渲染输入框，数组不能为空
5. 在表单填写内容，**直接按回车换行，不要手动写`\n`**
6. 点击【新增条目并保存Gist】写入云端，表单自动清空
